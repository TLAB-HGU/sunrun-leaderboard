DirMO-24 XGBoost with three multi_output_tree models, each jointly predicting 24 hours, using the frozen Top30 feature groups (237 columns per block). The existing DirMO-24 recipe is retained: 900 rounds, depth 3, learning rate 0.03, seed 42. Custom squared-error gradients and Hessians apply elementwise training weights of 4 for y>=550 km/s and 1 otherwise, normalized independently by each training-horizon mean. This is pointwise weighting, not block-wide sample weighting. ACE lag 0 and causal forward fill. Internal validation is chronological with a 72-hour target purge; F1/F2 target cutoffs are 2026-02-26 and 2026-05-29. No official-score tuning. Inherited Top30 feature selection was official-exposed, so these periods are not fresh holdouts. The direct parent is e2000fs_dirmo_24_feat30; e2000fs_feat30_pointweight4 is an additional scalar-LightGBM comparator. The published script replays archived forecasts, not live inference or retraining. Training source, nine boosters and per-round losses are archived; model inference timing is recorded separately in timing.json.
