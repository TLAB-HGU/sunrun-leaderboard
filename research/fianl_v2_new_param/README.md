# fianl_v2_new_param

`fianl_v2`(보드 행, Mean3 Total S 91.7499)에서 XGBoost 파라미터만 바꾼 재학습이다(2026-11-26, 사용자 요청). 입력, 블록 설계, 목적함수, continuation, offset, 후처리, seed는 `fianl_v2`와 같다. 파라미터 세트는 두 번 시도했고, 현재 코드와 보드 행은 2차 세트다.

## 바꾼 것

| 파라미터 | fianl_v2 | 1차 (교체됨) | 2차 (현재) |
|---|---:|---:|---:|
| `max_depth` | 3 | 3 | 2 |
| A 단계 라운드(`ROUNDS`) | 600 | 450 | 300 |
| `learning_rate` | 0.03 | 0.0151 | 0.0408 |
| `min_child_weight` | 20 | 27.7 | 31.1 |
| `reg_lambda` | 5 | 6.26 | 11.18 |
| `subsample` | 0.8 | 0.85 | 0.69 |
| `colsample_bytree` | 0.7 | 0.88 | 0.70 |

- `PARAMS`는 A 단계와 S-cap continuation(6 × 30트리)이 함께 쓰므로 두 단계 모두에 적용된다. continuation 라운드 수는 그대로다.
- 파라미터 값은 사용자가 준 표에서 가져왔다. 1차 표에 함께 있던 S 122.100, RMSE 85.09, TIMSE 33,355는 사용자 쪽 별도 탐색의 지표이고, 이 repo에서 재현한 값이 아니다.
- 입력 `data-v2/input/df.parquet`는 457열 판이다. 이 실험이 읽는 55열은 train/query 행 2,816,784개 모두에서 fianl_v2가 쓴 55열 판(`df.parquet.prev-55`)과 같다(NaN 위치 포함). 늘어난 것은 query 뒤(2026-09-27~)의 `live` 행뿐이고, 학습과 채점에는 쓰이지 않는다.

## 가설과 판정

- 사용자가 지정한 파라미터를 적용해 본 것이다. 사전 가설은 없다.
- 비교 기준은 `fianl_v2` Mean3이다: Total S 91.7499, F1 110.4670, F2 73.2933, F3 60.9654.
- 사용자 요청에 따라 결과와 상관없이 보드 행 `fianl_v2_new_param`으로 게시한다. 1차 게시 결과는 사용자 요청으로 store에서 지우고 2차 결과로 바꿨다.

```sh
CUDA_VISIBLE_DEVICES='' .venv/bin/python research/fianl_v2_new_param/experiment.py --threads 8
```

- 두 세트 모두 fianl_v2보다 나쁘다. 1차는 Total S +1.16(+1.27 %), 2차는 +1.82(+1.98 %)다. 세 seed 모두 같은 방향이다. 악화는 주로 F2와 F3에서 나왔다.
- RMSE는 두 세트 모두 세 기간 전부에서 fianl_v2(82.45 / 63.27 / 57.30)보다 컸다.
  - 1차: 학습률 × A 단계 라운드가 fianl_v2의 약 38 %다.
  - 2차: 그 값은 약 68 %다. 대신 depth 2, `reg_lambda` 11.18, `subsample` 0.69로 모형이 더 약하다.
  - 두 세트 모두 fianl_v2보다 적합이 약한 쪽이다. 과소적합일 가능성이 있지만 이 결과만으로는 확인되지 않는다.
