# e2000fs_calib_offset_roll_CDF

- 작성자: `seongeun`
- 상태: 종료, **게이트 실패 — 기준선 미반영**. 2026-11-13 사용자 요청으로 리더보드에 게시(3 seed 등가중 평균, mean3). 성능 개선 행이 아니라 대체 ablation 기록이다.
- 분류: `replacement ablation` — 기준선의 계단 가중치를 연속 CDF 가중치로 **대체**한다(누적 추가가 아님).

## 전략 (실행 전 작성, 2026-11-12)

### 가설

기준선 `e2000fs_calib_offset_roll`은 타깃 ≥ 550 km/s에 4, 그 밖에 1을 주는 계단 가중 제곱오차로 학습한다. 549와 551 km/s가 4배 차이 나는 불연속을 없애고, 타깃 속도의 분포 분위 F(v)에 비례하는 연속 가중을 주면 HSS 상승 구간 오차(TIMSE)가 줄어 S가 내려간다.

### 변경 요소 (하나)

| | 기준선 A | 이 실험 B |
|---|---|---|
| 타깃 가중 w(v) | `4 if v >= 550 else 1` | `F(v) = Φ(ln(v / s) / σ)` (로그정규 CDF, loc = 0) |
| 정규화 | lead별 평균 1 | 같음 |
| gradient / hessian | `w·error` / `w` | 같음 |

- 함수형은 `analysis/solar_wind_cdf_approx_2025_2026.ipynb`에서 로그정규·감마·Weibull 중 KS가 가장 작았던 로그정규(loc = 0, MLE)를 쓴다.
- **노트북의 상수는 쓰지 않는다.** 노트북 표본(2025-01 ~ 2026-09)은 F1/F2/F3 채점 구간 정답을 포함한다. σ와 s는 각 기간의 학습 행(`fit_F{n}`)에 있는 관측 타깃(ffill 전, 타깃 시각당 1개, 유한·양수)에 닫힌 해 MLE(`μ = mean(ln v)`, `σ = std(ln v)`, `s = exp(μ)`)로 다시 적합한다. 적합 표본의 마지막 타깃 시각이 cutoff보다 앞인지 코드에서 검사한다.
- 가중 범위를 1~4에 맞추지 않는다(사용자 결정). 그래서 저속 타깃의 가중이 매우 작다: F1 적합값(σ = 0.2085, s = 429.2) 기준 F(300) ≈ 0.04, F(450) ≈ 0.59, F(550) ≈ 0.88, F(700) ≈ 0.99.

### 유지 요소

특징 31개(상수 23 + lead별 8, `CONSTANT`·`VARYING` 그대로), XGBoost `PARAMS`, 900 rounds, 24-lead 블록 3개, prior 모델 + frozen per-lead offset(α 0.25, 336 origin), clip [1, 3000], seed 42/43/44, cutoff F1/F2/F3, 학습 라벨 ffill. 코드 diff는 `~/sunrun-cdf-weight/baseline-vs-cdf.diff`.

### 근거와 적용 범위

- Steininger et al. 2021, *Density-based weighting for imbalanced regression* (Machine Learning 110): 타깃 밀도(KDE)로 만든 연속 가중 함수로 드문 타깃의 손실 기여를 키워 드문 구간 성능을 개선했다고 보고한다. 신경망 회귀·밀도 역수 가중이며, 여기처럼 CDF를 가중으로 쓴 것은 아니다.
- Ribeiro & Moniz 2020, *Imbalanced regression and extreme value prediction* (Machine Learning 109), Silva et al. 2022 (SERA를 gradient boosting 목적함수로 사용): 타깃 값 → 연속 relevance 함수로 극단값 예측을 최적화한다. relevance는 분포 중심에서 0, 극단에서 1이며 양쪽 꼬리 모두를 다룬다.
- 두 문헌 모두 "연속 타깃 가중이 계단 가중보다 낫다"거나 "CDF 가중이 S(MSE·TIMSE)를 낮춘다"는 것을 직접 보이지 않는다. 이 실험의 기대 효과는 검증되지 않은 가설이다.
- 내부 선행 결과: 2026-11-10 point4 shape 캠페인 8개 arm과 LDS 가중(−0.22 S)은 모두 게이트를 통과하지 못했다. 저속 과대예측(+14 km/s bias)이 기존 약점이므로 이 가중은 bias를 키울 위험이 있다.

### 검증 기준 (사전 확정)

- 평가: 리더보드 F1/F2/F3만, 공식 scorer `lead-timse-6h-v1`. 내부 검증 없음. 채점 결과로 가중식을 다시 고르지 않는다.
- 기준선(같은 scorer·관측 파일): mean3 Total S 97.109 (seed 42/43/44 = 97.104 / 97.136 / 97.572), RMSE 67.53, bias +15.47.
- 성공: mean3 Total S ≤ 96.138(−1 %)이고, 3 seed 모두 같은 seed의 기준선보다 낮고, RMSE·bias에 중대한 악화가 없다.
- 그 외는 실패로 판정하고 보드에 게시하지 않는다. SOTA(S+ 95.516) 대비 2 % 개선 여부는 별도로 적는다.

### 실행 전 확인 (2026-11-12)

- smoke(F1, seed 42, 2 rounds): `make_objective`만 기준선 것으로 되돌리면 예측이 기준선 smoke와 완전히 같다. CDF 가중에서는 최대 5.0 km/s 달라진다.
- 같은 닫힌 해로 노트북 2025 표본(n = 5953)을 적합하면 σ = 0.213130, s = 475.617로 노트북 값과 같다.

### 판정

실패(보드 게시는 사용자 요청에 따른 것). mean3 S가 기준(≤ 96.138)에 못 미칠 뿐 아니라 3 seed 모두 기준선보다 1.9~2.6 나쁘다. SOTA(95.516) 대비로도 +3.84.

### 원인 분석

- 구현 오류·검증 불일치가 아니다: 가중 함수만 되돌린 smoke가 기준선과 같았고, scorer·관측 파일·특징·seed가 기준선과 같다.
- 가설 결함이다. w = F(v)는 저속 타깃의 가중을 거의 0으로 만든다(300 km/s ≈ 0.04, 계단 가중에서는 1). 모델이 저속 구간을 무시하고 예측을 위로 올려 과대예측 bias가 +15.5 → +21.5로 커졌다. lead가 길수록 심하다(72 h 근처 +22.9 → +31.5).
- 저속 구간이 많은 기간일수록 손해가 크다: F3은 bias +14.0 → +26.1, RMSE +6.3, S +4.1. 고속 사건이 많은 F1은 RMSE가 약간 내려갔지만(83.20 → 82.78) TIMSE가 +4.8 % 나빠져 S는 오른다.
- 기대했던 TIMSE 개선은 어느 기간에서도 나오지 않았다. 계단의 불연속 자체는 병목이 아니고, 저속 구간의 가중 하한(계단의 1)이 필요하다는 결과다.
- lead 13~24 h에서 S 악화가 가장 크다(+3.1~+5.6).

### 다음 실험 채택 여부

채택하지 않는다. 기준선은 계단 point4 그대로 둔다. 가중 모양 축은 2026-11-10 point4 shape 캠페인 8개 arm과 이번 실험까지 모두 게이트를 넘지 못했다. 하한이 있는 변형 `1 + 3·F(v)`는 사용자 지시(2026-11-13)로 `e2000fs_calib_offset_roll_CDF_1p3F`에서 따로 실행한다.
