# union9_lbsel에 물리 특징 4개 추가

사용자가 직전 표에서 지정한 1~4위 특징을 함께 추가한다. 기준선은 게시된 union9_lbsel의 Mean3 Total S 92.108515다.

| 추가 특징 | 적용 리드 | 검증할 기전 |
|---|---|---|
| CME 도착 위상 × 27일 반복류 | 1–72h | 도착 가능성이 높은 리드에서 배경류 대비 가속 신호를 구별 |
| SUVI 코로나홀 경도 폭 | 49–72h | 코로나홀의 공간 폭으로 장기 고속류 지속을 표현 |
| SUVI 탄도 경도대 암부 대비 | 49–72h | 이동속도에 따른 지구 연결 경도대의 암부 차이를 표현 |
| 27일 전 풍속 상승률 | 1–72h | 이전 회전 고속류의 진입 시점과 상승 크기를 표현 |

원래 블록별 225/225/228열과 순서를 유지한다. 추가 후 블록별 273/273/278열이다. 학습 라운드, S-cap, offset, 고정 seam xf8, 기존 ridge 혼합, 3시간 위상 전진 및 시드 합의 보정을 유지한다. 시드 합의 보정에는 세 시드의 예측이 함께 필요해 재현 가능한 완성 모델은 42·43·44를 모두 학습한다. 개별 시드 단독 점수로 보정된 최종 모델의 동등한 조기 판정은 불가능하다.

공식 F1/F2/F3에서 Mean3 S, 동일 시드별 S, Total과 기간별 RMSE·TIMSE를 비교한다. 채택 검토 기준은 Mean3 S 1% 감소와 보조 지표 가드레일이다. 네 특징은 공식 평가 결과를 참고해 선택했으므로 탐색적 결합 실험이다. 각 학습은 해당 기간 cutoff 이전 데이터만 사용한다.
