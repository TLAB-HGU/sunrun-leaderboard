arm 목록의 성격

같은 실험의 변형(시드·손실·마스크 차이)이 대부분이라 서로 닮은 예측이 많습니다 — 7절에서 측정합니다.

기준(base)은 무엇인가

calib4 detpool_gpd의 최종 예측입니다. 즉 이미 한 번 최적화된 산출물에 다시 스택을 얹는 구조이고, 스택의 β는 “기준에서 얼마나 벗어날지”를 정합니다.

기준 성적MSE · ≥550 · bias
3 · 조합식

기준에서 출발하는 비음수 볼록 결합

pred[i] = base[i] + Σj βj · ( armj[i] − base[i] )
βj ≥ 0,   Σj βj ≤ 1

β를 base-상대 증분에 걸기 때문에 β = 0이면 정확히 기준이고, Σβ ≤ 1이면 “기준과 arm들의 볼록 결합” 범위를 벗어나지 않습니다. 음수를 금지하는 이유는 해석 가능성입니다 — βj는 “arm j 쪽으로 얼마나 이동했는가”가 됩니다.

주의. Σβ ≤ 1은 볼록결합이라 예측을 “평균 쪽으로 당깁니다”. 서로 다른 arm의 평균은 대개 분산이 작고 꼬리가 눌린 예측이므로, 이 제약 자체가 꼬리에 불리한 방향으로 작동할 수 있습니다. 실제로 detroute에 26%가 실렸습니다(6절).
4 · 적합 절차

매 168 원점마다, 성숙한 과거만으로 다시 푼다

창과 성숙

사용 구간 = [ 최근 2,160 성숙 원점 ]  ·  성숙 조건 = 목표 시각 ≤ 재적합 원점
재적합 주기 = 168 원점  →  전체 회

채점 대상 원점의 정답은 절대 쓰지 않습니다. 72시간 성숙 조건이 그 경계입니다.

표준화 → NNLS + 리지

Xj = Δj / rms(Δj)  // arm별 증분 스케일 정규화
min ‖ [X ; √(ridge·n)·I] β − [resid ; 0] ‖,   β ≥ 0  // scipy.nnls
β ← β / rms  // 원래 단위로 되돌림

표준화가 없으면 스케일이 큰 arm이 무조건 선택됩니다. 리지는 1e-3·n_rows로 약하게 겁니다.

심플렉스 캡 → 꼬리 가드

Σβ > 1 이면 β ← β / Σβ
s ∈ {1.0, 0.75, 0.5, 0.25} 를 차례로: tail(w) ≤ tail(base) 인 첫 s 채택
모두 실패하면 β = 0 (그 구간은 기준 그대로)

가드는 “trailing에서 나빠지지 않기”만 요구합니다. 꼬리를 개선하라는 압력은 없습니다 — 9절의 핵심.

사다리가 만드는 이산값 원래 합이 S0일 때 각 단의 합 = min(1, S0·s). 그래서 실제 Σβ는 0 · 0.5 · 0.6 · 1 같은 몇 개 값에만 몰립니다(6절 분포). 연속적으로 조금씩 섞는 것이 아니라 “몇 %로 줄일지”를 네 단계 중에서 고르는 구조입니다.

6 · β는 어디에 실렸나

detroute 26%, 나머지는 잘게 — 그리고 절반의 시점은 β=0

평균 β 상위 arm

막대 = 평균 β. 오른쪽 숫자 = 그 arm 단독 성적의 기준 대비 증감(MSE / ≥550). detroute는 단독으로 보면 기준보다 둘 다 나쁜데 가장 큰 가중을 받았습니다.

β 합의 분포

재적합마다 다시 정해지는 β

168 원점마다 계단처럼 바뀝니다. 파랑 = Σβ, 주황 = detroute β. β=0 구간(회색)은 가드가 전부 실패한 구간입니다.

7 · 상관 구조

“81개 고상관 arm”이라는 말을 측정해 보면

arm들이 서로 얼마나 닮았는지는 무엇의 상관을 재는지에 따라 달라집니다. 두 가지를 모두 쟀습니다.

수준(예측값) 상관은 중앙값 0.94로 매우 높지만, base-상대 증분의 상관은 중앙값 0.35로 훨씬 낮습니다. NNLS는 증분에 걸리므로, “고상관이라 잡음만 더해진다”는 설명은 절반만 맞습니다 — 실제로는 서로 다른 방향의 증분이 섞이며, 그 조합이 꼬리를 눌렀습니다.

숫자

셀의 86%가 ±5 km/s 안입니다. 그런데 그 작은 이동이 꼬리에서 손해가 됩니다 — 고속 셀은 수가 적어 조금만 눌려도 MSE 기여가 크게 바뀝니다.

9 · 성적

전부 붙이면 나빠진다 — 어디서 나빠졌나

구간별

왜

  • 목적함수가 총 MSE입니다. 총 MSE는 몸통(정상 구간)이 지배하므로, 꼬리를 좋게 하는 arm보다 몸통을 안정화하는 arm이 선택됩니다.
  • detroute 26%가 정확히 그 선택입니다. detroute는 단독 성적이 기준보다 나쁘지만, 스택에 넣으면 총 MSE를 낮추는 방향(분산 감소)으로 작동합니다.
  • 가드는 “나빠지지 않기”만 요구합니다. 그래서 꼬리 개선 압력이 0입니다.
  • 리지 1e-3은 약합니다 — β가 0이 아닌 셀이 5.5%(=22,344/402,570)이고, Σβ는 43.9%의 시점에서 캡 1에 붙습니다.
10 · 반사실 진단

detroute 가중만 0으로 두면 어떻게 되나 (사후 진단)

사전등록 결과가 아니라 설명용 진단입니다. 저장된 β에서 detroute 열만 0으로 두고, 나머지 β는 그대로 써서 다시 조립·채점했습니다.

해석: detroute 가중을 빼면 총 MSE는 나빠지고(3243.1 → 3258.2) 꼬리는 좋아집니다(7072.8 → 6981.0). 즉 detroute 26%는 “총 MSE를 사고 꼬리를 파는” 거래였습니다. 사전등록된 목적함수가 총 MSE였으므로, 이 선택은 규칙에 충실한 결과입니다 — 규칙이 틀렸다는 것이 이 실험의 결론입니다.
