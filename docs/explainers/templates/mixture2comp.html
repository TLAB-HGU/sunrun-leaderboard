01 / Raw — 원자료에서 시작6 sources · 36,015 h
RAW

모델의 첫 입력은 위성 관측과 모델 실행 파일이다

예측 파일은 이 원자료들의 결과물입니다. 그래서 여기서부터 시작합니다.

모델 입력 237열의 모든 값은 아래 원자료에서 나옵니다. ACE 위성의 시간당 스냅숏, GOES-18 SUVI 영상의 경도·위도 패치, 코로나홀 지도, WSA-Enlil 실행 파일 — 이 넷을 1시간 격자에 맞춘 뒤 특징으로 바꿉니다.

SUVI 경도 스트립 — “도달 시각 h에 지구로 흘러오는 태양면은 어느 경도인가”

태양 자전 0.55°/h, 태양–지구 거리 147,858,620.7 km. 속도 v인 유체가 h시간 뒤에 도착한다면 그 유체는 h + age 시간 전에 태양면을 떠난 것이므로 유효 경도는 λ = Ω·(τ_v − (h + age)), τ_v = D/v 입니다. 이 λ를 중심으로 ±5° 띠의 이미지 통계를 가중 평균해 strip_v*를 만듭니다.

// 원자료(이미지 패치) I[lon][lat] · 경도 12칸 × 15° = −90…+90
// 띠 가중치 w_i = |[λ−5, λ+5] ∩ cell_i| / 10
strip_v550_logmed(h) = Σ w_i · log_median_i / Σ w_i
// 커버리지 < 0.5 이면 NaN, age > 6h 면 stale
왜 속도별로 띠가 다른가 — 빠른 유체(750 km/s)는 55시간, 느린 유체(350 km/s)는 117시간 만에 도착합니다. 같은 도달 시각이라도 출발 경도가 다르므로 띠를 5개 속도로 나눠 각각 계산합니다. 느린 유체일수록 더 서쪽(더 이른 시각)에서 출발합니다.

09 / Head 3 — gap3 boosters · event rows
H3

“돌파했을 때는 얼마인가”를 따로 배운다

학습 행을 이벤트가 있는 행으로 제한하고, 라벨은 그 블록 평균에 대한 잔차입니다.
rows = { i : 블록 b의 24시간 안에 y ≥ 550 이 하나라도 있음 }
m_b,h = meanrows( y_h ) // 블록 b, horizon h 의 이벤트 평균
label = y_h − m_b,h // 잔차만 학습 (base_score = 0)
gap_h = tree_h + m_b,h // 추론 때 평균을 다시 더함

이벤트 평균 m (블록0, h1–12)

왜 평균을 빼는가 — 이벤트 셀은 14.7%, 이벤트 행은 25.7%뿐입니다. 트리가 “전체 수준”까지 배우면 과적합됩니다. 평균을 빼면 트리는 모양(어느 horizon이 더 높은가)만 배우고, 수준은 상수로 되돌립니다.
10 / Compose — 손풀이72 equations
MIX

세 헤드를 한 줄로 합친다

horizon마다 p가 다르므로, 72개 식이 각각 다른 비율로 섞입니다.
pred_h = level_h + p_h · (gap_h − level_h) = (1 − p_h) · level_h + p_h · gap_h
pred_h = clip(pred_h, 1, 3000)

즉 “몸통 평균”과 “이벤트 평균”의 가중평균이고, 가중치가 곧 그 horizon의 돌파 확률입니다. p가 0에 가까우면 level 그대로, p가 1에 가까우면 gap으로 이동합니다.
