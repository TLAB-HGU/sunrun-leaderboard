이 실험은 point4 레시피(3블록 × 24출력 벡터 트리, Top30 237열, 900 라운드, 깊이 3, η 0.03)를 한 글자도 바꾸지 않고 학습 원점 조건만 origin + 72h < 컷오프에서 origin + 144h ≤ 컷오프로 바꿨습니다. 학습 원점이 23개 줄었을 뿐인데 통합 MSE는 3556.2 → 3491.0, 고속(≥550) MSE는 5923.5 → 5763.5가 됐습니다.

0 · 한눈에

바꾼 것은 마스크 하나, 결과는 두 지표 모두 개선

이 실험이 따로 제출된 이유. 원래 이 모델은 e2000fs_calib_tweedie15 실험의 짝 control(point4 arm)입니다. 손실 비교를 공정하게 하려고 마스크를 144h로 맞췄는데, 그 마스크 자체의 효과를 분리해서 보려고 단독 실험으로도 제출했습니다. 그래서 “부모(72h) vs 이 실행(144h)”이 곧 마스크의 순수 효과입니다.
1 · 무엇이 달라졌나

학습에 넣는 원점 집합이 조금 줄어든다

부모: { t : t + 72h < 컷오프 }   // 라벨 창의 끝이 컷오프보다 앞
이 실행: { t : t + 144h ≤ 컷오프 }   // 라벨이 끝난 뒤 72h 여유까지 요구

두 조건의 차이는 “72시간 더 이른 시점까지”입니다. 학습 라벨은 y[t,1..72]이므로, 부모는 마지막 라벨이 컷오프 직전까지 닿고, 이 실행은 마지막 라벨이 컷오프 72시간 전에서 끊깁니다. 모델 구조·입력·라운드·시드 어느 것도 바뀌지 않았습니다.

회색 = 학습 라벨 구간, 주황 = 이 실행이 잘라낸 72시간, 파랑 = F1 평가 시작.

2 · 왜 144h인가

“예측 72시간 + 라벨 확정 72시간” — 그리고 부모가 놓친 2시간

72시간 예측 모델의 학습 라벨 y[t,h]는 t+h 시점의 관측값입니다. 그런데 관측값이 확정·공개되기까지의 지연이 따로 있습니다. 두 조건을 라벨의 관점에서 다시 쓰면 차이가 분명해집니다.

부모: origin + 72h < 컷오프  ⟺  라벨 끝 < 컷오프  // 라벨이 “그 시각에 존재”하기만 하면 됨
이 실행: origin + 144h ≤ 컷오프  ⟺  라벨 끝 + 72h ≤ 컷오프  // 라벨이 “확정”된 뒤 72h 여유

즉 144h 마스크가 실제로 보장하는 것은 “컷오프 시점에 모든 학습 라벨이 확정돼 있다”입니다. 부모의 72h 조건은 라벨이 컷오프보다 앞선 시각이라는 것만 보장하고, 그 라벨이 관측·확정됐는지는 보장하지 않습니다.

3 · 3시간 격자

72시간을 더 자르면 원점은 72개가 아니라 23개가 빠진다

학습 원점이 매시간이 아니라 3시간 간격이기 때문입니다. 전체 10,688개 원점의 간격이 모두 정확히 3시간입니다 (2022-10-01 ~ 2026-05-28). 그래서 72h ÷ 3h = 24 근처, 경계 포함 조건 때문에 실제로는 23개가 빠집니다.

마스크별 학습 원점 수

F1·F2 모두 정확히 23개씩 줄어듭니다(전체 학습 원점의 약 0.22%).

빠진 원점 (F1)

연속된 3시간 격자 블록입니다 — 즉 “최근 사흘”을 통째로 뺀 것과 같습니다.

7 · 효과의 크기

원점 23개를 바꾼 효과가 우연인가

원점을 단위로 짝(pair) 부트스트랩을 돌렸습니다. 같은 원점 집합을 복원추출해 두 arm의 차이를 4,000번 다시 계산했습니다. 두 예측은 같은 원점·같은 정답을 공유하므로 “차이”의 분포를 직접 볼 수 있습니다.

95% 구간

해석

  • 통합 MSE 차이는 구간 전체가 0 아래입니다 — 개선 방향이 일관됩니다.
  • 고속 MSE 차이도 구간이 0 아래로, 폭이 더 넓습니다(꼬리는 셀 수가 적어 분산이 큽니다).
  • 그런데 개선된 원점은 절반 남짓(51%)입니다. 평균 개선은 소수의 큰 오차 원점에서 나옵니다.

왜 최근 사흘을 빼면 좋아지는가 — 후보 세 개

  1. 라벨 확정 지연: 부모는 성숙하지 않은 마지막 라벨까지 학습합니다(위 2절). 그 라벨이 이후 값으로 정정되면 모델이 잘못된 최근값을 외웁니다. — 이 설명은 최근 구간을 빼면 좋아진다는 관측과 맞습니다.
  2. 최근 구간의 급변: 컷오프 직전 사흘이 특이하게 변동이 크면, 그 구간을 빼는 것만으로도 스케일(정규화 상수·base_score)이 덜 흔들립니다.
  3. 단순 변동: 23개 원점은 전체의 0.22%라 적합 자체가 크게 달라지지 않습니다. 실제로 예측 차이는 중앙값 0에 가깝습니다(5절).

이 페이지의 데이터로는 1과 2를 분리할 수 없습니다. 다만 관측된 방향(두 폴드 모두 개선, 꼬리에서 더 크게)은 1과 일관됩니다 — 다음 실험에서 “성숙 지연을 74h/96h로 늘리면 더 좋아지는가”로 검증할 수 있습니다.

따라서 말할 수 있는 것: “144h 마스크는 이 레시피에서 평균적으로 총 MSE와 꼬리 MSE를 개선했다.” 말할 수 없는 것: “모든 원점에서 더 좋다”, “다른 레시피에서도 그렇다”.

9 · 위치와 맥락

이 실행이 파이프라인에서 차지하는 자리

tweedie15의 짝 control

이 모델(144h 마스크의 point4)이 tweedie15 실험의 control arm입니다. 같은 마스크·같은 라운드로 Tweedie 손실과 짝을 이뤄 비교했고, 그 비교에서 Tweedie는 총 MSE를 −7.5% 개선하고 꼬리를 +63.5% 악화시켰습니다.

detroute의 body

현재 제출 계보에서 평소 구간 예측은 Tweedie arm이 담당하고, 이 point4 arm은 그 비교 기준입니다. 즉 이 페이지의 마스크 효과는 이후 모든 실험의 기본 타이밍이 되었습니다.

계보에서의 자리

부모 72h 판본은 통합 3556.2 / 꼬리 5923.5, 이 실행은 3491.0 / 5763.5입니다. 다만 이 실행이 detroute의 body가 된 것은 아닙니다 — body는 tweedie15 arm이고, 이 실행은 그 짝 비교 기준으로 남았습니다. 계보에 남은 것은 성능이 아니라 마스크 규칙(origin+144h)이고, 그 규칙이 이후 실험의 표준이 됐습니다.
