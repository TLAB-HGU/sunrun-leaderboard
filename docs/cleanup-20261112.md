## 바뀐 구조

- `research/{보드 표시 이름}/` = `experiment.py`, `README.md`, `logs/`, `results/`, `visualization/`, `weights/`(로컬). 하위 폴더 없음.
- 결과 `results/{tag}_predictions.parquet`·`{tag}_score.json`, 체크포인트 `weights/F{n}_s{seed}.npz`. 각 `experiment.py`의 출력 경로를 같이 고쳤다.
- `_mean3` 폴더 5개는 보드 표시 이름으로 바꿨다(제출 ID는 `EXPERIMENT`에 그대로).
- 시각화 3개(`drop_t035_v650`, `drop_t035_equatorial`, `negative_combined`)를 `research/{실험}/visualization/`으로 옮기고, 생성·링크 게시 코드는 `tools/`로 옮겼다.

- GBM 11개 행을 `--predict-only`로 다시 돌려 seed별·mean3 예측이 저장된 parquet와 동일하고 공식 점수가 일치함을 확인했다. `naive`는 전체 재실행 결과가 동일하다.
