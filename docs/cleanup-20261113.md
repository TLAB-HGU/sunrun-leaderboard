# 2026-11-13 정리: research/module 모듈화 · research/result 산출물 분리 · 잔재 삭제

사용자 지시: experiment.py의 중복 항목은 `research/module/`로 빼서 모듈화하고, 산출물은 `research/result/`에서
관리하며, 남은 잔재는 삭제한다. 결정 사항: GBM은 공용 러너까지 모듈화, `results/`와 `logs/`를 이동
(`visualization/`은 board.py가 `research/<실험>/visualization` 링크를 고정 검증하므로 그대로 둠).

## 변경

| 항목 | 이전 | 이후 |
|---|---|---|
| 실험 코드 | `research/*/experiment.py` 20개, 9,015줄(~4,200줄이 파일 간 동일 함수) | experiment.py 20개 + `research/module/` 8개, 2,428줄 |
| GBM 행(14) | 행마다 458–748줄 | 47–132줄(`gbm.GBMSpec` 선언: 특징, 목적함수, 보정 설정) |
| 베이스라인(5) | 181–224줄 | 49–92줄(`baseline.main`) |
| 산출물 | `research/{실험}/results/`, `logs/` | `research/result/{실험}/results/`, `logs/` |

`research/module/`:
- `common.py`: 출력 경로(`--out` 없음 → `research/result/{실험}`, weights는 실험 폴더), JSON-lines `Logs`, 공식 scorer 호출, 결과 파일, mean3
- `table.py`: df.parquet 적재, 특징 ffill, 학습 라벨 ffill, origin × 72 lead 격자
- `calibration.py`: prior/calibration 분할, frozen per-lead offset, clip
- `objectives.py`: point4(+spectral, Hessian-only spectral), lognormal-CDF 가중, TIMSE 계수
- `continuation.py`: scap·splus의 A900 + direct-S continuation
- `gbm.py`: 24-lead 블록 XGBoost 러너(train, `--predict-only`, `--smoke`, checkpoint)
- `baseline.py`: SWEPAM 시계열, query origin, 베이스라인 러너

`--out DIR`을 주면 예전과 같이 `DIR/results`, `DIR/logs`, `DIR/weights`(+ sunrun용 `DIR/F{n}_metadata.json`)에
쓴다. `scripts/*/*/*.py` 재현 래퍼는 수정하지 않았다.

통일된 부수 동작(예측과 무관): `Logs`의 중복 stdout 출력 제거, 모든 GBM 행이 `logs/F{n}_s{seed}_metadata.json`
(vanila 형식 상위집합)을 기록, `load_grid`의 inf 검사를 전 행에 적용, `ROOT` 탐색 통일.
