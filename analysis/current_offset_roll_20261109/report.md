# 현재 e2000fs_calib_offset_roll의 성능 병목

## 결론

**주 병목은 드문 고속 태양풍 이벤트의 진폭을 충분히 예측하지 못하는 현상이다.**
현재 실제 제출 예측에서 ≥700 km/s인 **634개 평가 쌍(전체의 1.205%)**이
공식 Total TIMSE의 **81.37%**를 차지한다. 이 구간 평균 편향(pred−truth)은
**−151.12 km/s**, RMSE는 **187.62 km/s**이다. 같은 현상이 세 seed 모두에
나타나므로 seed 평균 때문에 새로 생긴 문제로 보기 어렵다.

이는 **점수 손실이 발생하는 위치와 실패 형태에 대한 높은 신뢰도의 직접 증거**이다.
특징 정보 부족, 모델 용량/정규화, 학습 목적함수와 공식 지표의 차이 중 무엇이
이 현상을 주로 만드는지는 현재 결과만으로 인과적으로 확정할 수 없다.

48개 이상 유효 target이 있는 765개 origin에서, 동일한 유효 지평에 한정한
72h 관측 range 중앙값은 168.10 km/s, 예측 range 중앙값은 87.94 km/s이다.
origin별 range 비율의 중앙값은 **0.510**이다. 이는 순수한 진폭 계수의 추정이나

세 seed의 ≥700 편향은 −148.24/−153.89/−151.22 km/s, TIMSE 기여는
81.06/81.75/81.28%, range 비율 중앙값은 .518/.519/.512이다.
따라서 seed 평균이 파형을 조금 평탄하게 만들 가능성은 있으나, 압축의 주된 현상은
각 단일 모델에도 이미 존재한다.

### 소수 관측 시각에 손실이 집중된다

고유 target 상위 1/5/10/24시간이 Total TIMSE의 **8.91/31.85/45.03/66.57%**를
차지한다. 최대 기여 시각은 **2026-01-19 22:00 UTC, 1080.3 km/s**이다.
이 시각은 12개의 origin/lead 쌍에 채점된다. ≥700인 634개 쌍은 **53개 고유
관측 시각**에 대응하며, 634개의 독립적인 이벤트가 아니다.

F1 관측이 pooled Total TIMSE의 **70.69%**, F1의 ≥700 구간만 **60.64%**를
차지한다. 가장 큰 교차 셀은 F1·25–48h·≥700으로, Total TIMSE의 약25.88%이다.
이는 Total에 고정된 quantile/가중치를 사용한 기여이고 기간별 S 평균과 다르다.

## 4. 인과 후보의 증거와 한계

|설명|증거 수준|판정|
|---|---|---|
|고속 진폭 압축과 이벤트 집중|현재 제출 직접 검증, 높음|주된 관측 병목|
|장기 지평 변화 예측 부족|현재 제출 직접 검증, 높음|보조 병목; missing information과 모델 적합 문제는 미분리|
|offset이 주원인|현재 no-offset 산출물 직접 비교|지지되지 않음. 제거하면 Total S 악화|
|공통 도착 시각 지연|현재 고정 shift 비교|전체에서는 지지되지 않음. 국소 오류는 미배제|
|모델 용량/목적함수/학습 라벨 정책|현재 코드 사실 + 부모 실험|가능한 원인이나 우선순위 인과 판정 불가|
|ACE 입수 지연·서빙 ffill|다른 구성의 별도 실험|추가 운영 비용이며 현재 오프라인 손실의 원인으로 확정 불가|

**현재 offset 직접 확인:** 같은 현재 run의 저장 no-offset 예측을 재채점했다.
mean3는 offset 없이97.254077, 적용 후96.310745로 **0.943332 개선**한다.
세 seed도 각각0.895294/0.965742/0.970312 개선한다. ≥700 mean3 편향도
−157.04→−151.12, RMSE193.15→187.62로 개선한다. 다만 F2 S는 +0.220522,
F3는 +0.082614 악화하므로 모든 기간에 이득이라는 주장은 하지 않는다.
현재 offset은 훈련 calibration 마지막336행의 잔차평균×.25이며, 평가 중 새 정답으로
갱신하는 online rolling offset이 아니다.

**구조 사실:** 현재 모델은 depth3·900 rounds·24h block 3개·공유 multi-output tree,
tail4@550와 spectral 계수.1을 유지한다. 이 학습 목적함수는 공식
`mean_h((MSE_h×TIMSE_h)^.25)`와 같지 않다. 이는 코드로 확인되지만 목적함수
교체로 개선된다는 인과적 근거는 아니다.

**부모 모델에서만 확인된 근거:** 훈련에서도 고속 과소예측이 존재하고 300→900 rounds의
훈련 적합은 개선된다. 개별 output tree로 바꾸면 훈련 적합이 좋아져도 공식 고속
꼬리가 악화했다. 단순한 tree 자유도 확대나 무조건적인 rounds 증가를 해결책으로
확정하지 않는다. 시간가중 실험도 실패했다. 이 결과들의 수치를 현재 mean3 결과로
귀속하지 않는다.

**데이터/서빙:** 학습의 ffill-label 정책은 유지되지만 채워진 값이 항상 작다는 증거는
없다. 공식 정답은 결측을 보간하지 않고 제외한다. 기존 ACE 지연 실험은 옛30특징 A에서
1칸 ffill의 평균 +1.374 S 비용을 측정했으며 현재 lag mean3의 측정값이 아니다.
관측 timestamp만으로 실제 공개/입수 시각을 알 수 없다. 독립 Wind 기록은 매우 빠른
태양풍 자체를 일부 지지하지만 정확한 ACE 시간평균 정답의 품질을 완전히 증명하지 않는다.

## 5. 민감도, 다음 판단과 한계

공식 표본·quantile·가중치를 고정하고 지정 그룹의 오차 에너지만 0으로 만드는
**진단용 대수적 민감도**는 다음과 같다. 새 예측이나 달성 가능한 성능이 아니다.

|오차만 제거한 그룹|남는 S|조건부 감소|
|---|---:|---:|
|≥700|61.414717|36.23%|
|25–48h|60.307224|37.38%|
|49–72h|61.081637|36.58%|
|F1 전체|59.626070|38.09%|

이 효과들은 겹치며 합산할 수 없다. **TIMSE의81.37%를 설명한다는 것은 S의81.37%를
해결할 수 있다는 뜻이 아니다.** 저·중속의 MSE도 남으므로 고속 사건만으로 모든
오차를 설명하거나 해결할 수 없다. 표의 지평 그룹은 길이도 다르다.

최소 다음 단계는 **이미 진행 중인 학습 loss/label-mask 통제 실험의 완료 산출물을
먼저 확인**하는 것이다. 같은 정책의 중복 학습을 생성하지 않는다. 기존 결과가
현재 부모/특징 집합을 보존하지 않으면 현재31개 특징을 고정한 후, 원관측 label만
학습에 사용하도록 loss mask 하나를 바꾸는 matched-seed 통제를 별도 사전 등록한다.
해당 통제는 가설 제안일 뿐 이 진단에서 실행하지 않았다. fitting 중 label support,
고속/저속 편향, 지평별 손실을 함께 기록해야 label 정책과 적합 압축을 구분할 수 있다.
과거 부모의 결과가 이를 이미 충족하는 경우 먼저 그것을 사용한다.

F1/F2/F3는 반복 노출된 benchmark이다. 이 보고서는 고정 예측에 대한 기술적 진단이며
새 일반화 성능·통계적 유의성·개선량을 주장하지 않는다. 새 모델 선택, 계수 적합,
정답 제거, 예측 재조합 파일 저장, 게시를 수행하지 않았다.
